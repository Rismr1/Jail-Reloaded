  Choose the size accepted by the destination's upload form. Banners share

  tiny icon sizes; use the banner alongside the icon to display the credit.

  All lettering is converted to vector paths, so no font installation is
  required. SVG groups identify the mascot, wordmark, author credit, and
  background design. Open in a vector editor to change colors or layout.
  Transparent icon/wordmark versions use dark author credits intended for
  light backgrounds. Matching PNG versions are included.

Design
  Original blue:       #0071BC
  Outline:             #231F20
  Deep navy:           #0C1824
  Slate blue:          #15394D
  White:               #FFFFFF

  The original jailer was redrawn with Bezier vector paths to clean the
  edges while preserving the cap, uniform, pipe and pointing pose. The
  title follows the reference's Kabel-style lettering, including the
  diamond dot above the i. The banner uses geometric shapes, gradients
  and subtle vertical bars. No AI image generation was used.
